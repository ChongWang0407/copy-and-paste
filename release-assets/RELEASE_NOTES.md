# Copy & Paste v1.0

一款专为 macOS 打造的轻量化开源剪贴板工具。

## 下载与升级

下载下方 `Copy-and-Paste_1.0.dmg`，打开后将 `Copy & Paste.app` 拖入“应用程序”。已有用户请先退出 App，再替换旧版；无需卸载或删除数据。Source code 压缩包为源码，并非安装包。

当前安装包仅支持 Apple 芯片，要求 macOS 14 或更新版本。采用 ad hoc 签名，尚未经过 Apple 公证。若 macOS 阻止打开，请先关闭弹窗，再到“系统设置 → 隐私与安全性 → 安全性”中点击“仍要打开”，随后确认打开。详见仓库 README 的四步安装图与 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。首次启动时按应用提示授权辅助功能，以便向其他应用粘贴。

## 本次调整

- 正式版默认数据目录改为 `~/Library/Application Support/com.copypaste/`，开发版为 `com.copypaste.dev`。
- 首次启动自动迁移对应旧目录，保留数据库、附件、收藏、设置与密钥，更新媒体和背景路径；自定义目录和便携模式继续沿用。
- 已有有效新目录时优先使用，不合并两套记录；迁移失败时保留可恢复数据并提示，支持重新启动后恢复。
- 更新 README、海报、安装说明和隐私说明，移除旧演示图。
- 应用内部版本仍为 `1.0.0`；Bundle ID、钥匙串与启动项身份不变。

自动记录、搜索分类、图片文字识别、批量粘贴、三种复制提示、常用内容与编辑，以及 macOS 26 及以上的系统中英翻译，详见 README。
